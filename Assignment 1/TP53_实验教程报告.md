## 1. 背景知识

### 1.1 基因、蛋白与密码子

基因是 DNA 上的一段序列。编码区的每三个碱基构成一个密码子（codon），对应一个氨基酸（amino acid）。氨基酸连成多肽链，折叠后成为有功能的蛋白。人的 TP53 基因编码的 p53 蛋白长 393 个氨基酸。

蛋白序列通常用一字母代码书写：A 代表丙氨酸，R 代表精氨酸，H 代表组氨酸，G 代表甘氨酸，C 代表半胱氨酸，W 代表色氨酸，Q 代表谷氨酰胺，D 代表天冬氨酸，V 代表缬氨酸，S 代表丝氨酸，L 代表亮氨酸，P 代表脯氨酸。

基因突变按对蛋白的影响分为几类，本文会反复用到这些名称：

- 错义突变（missense mutation）：一个密码子变成另一个氨基酸的密码子，蛋白长度不变，只替换一个氨基酸。例如 R175H 表示第 175 位的精氨酸（R）被组氨酸（H）替换。
- 无义突变（nonsense mutation）：密码子变成终止密码子，翻译提前结束，蛋白被截短。书写时用星号表示，例如 R213*。
- 移码突变（frameshift）：插入或缺失的碱基数不是 3 的倍数，阅读框整体移位，下游氨基酸全部改变。
- 剪接位点突变（splice site mutation）：影响 mRNA 剪接，可能产生异常转录本。
- 同义突变（silent mutation）：密码子改变但氨基酸不变。

### 1.2 p53 蛋白的结构域

结构域（domain）是蛋白中能够独立折叠并执行特定功能的一段区域。本文采用下面的划分，编号对应人 p53 的 1 至 393 位：

- TAD1（1–40）与 TAD2（41–60）：转录激活结构域（transactivation domain），负责与转录机器及其他蛋白结合。
- PRD（61–101）：富含脯氨酸的结构域（proline-rich domain），并包含至 DBD 起点之间的相邻片段。
- DBD（102–292）：DNA 结合结构域（DNA-binding domain），负责识别并结合特定的 DNA 序列，内部结合一个锌离子（Zn²⁺）。
- Linker（293–324）：连接区。
- TET（325–356）：四聚化结构域（tetramerization domain），p53 以四聚体形式发挥功能。
- CTD（357–393）：C 端调节结构域（C-terminal domain）。

不同文献对这些边界的划分略有差异，例如 DBD 有时写作 94–292、95–288 或 100–288。本文以 UniProt 的注释为准：DBD 采用 102–292，TET 采用 325–356；TAD1/TAD2 沿用常规示意，PRD 取 61–101 以衔接至 DBD 起点。

### 1.3 癌症中的 TP53 突变

TP53 是抑癌基因（tumour suppressor gene）。它的正常功能包括在 DNA 损伤时暂停细胞周期、启动 DNA 修复或诱导细胞凋亡。功能丧失会使受损细胞继续增殖。

突变按来源分为两类：

- 体细胞突变（somatic mutation）：在肿瘤细胞中获得，不遗传给后代。
- 胚系突变（germline mutation）：来自父母，存在于全身细胞，例如 Li-Fraumeni 综合征中的 TP53 胚系突变。

突变按对肿瘤的作用分为两类：

- 驱动突变（driver mutation）：为肿瘤提供生长或存活优势，在肿瘤中受到正选择。
- 伴随突变（passenger mutation）：随突变过程产生，对肿瘤没有明显好处，也没有被清除。

热点（hotspot）指在大量独立肿瘤中反复出现的同一个密码子突变。单篇研究的样本量通常不足以判断一个位点是否属于热点，因此需要汇总数据库。

### 1.4 为什么要做跨物种比较

直系同源基因（ortholog）指不同物种中由同一个祖先基因演化而来的基因。人、牛、鼠、鸡、蛙、斑马鱼的 TP53 互为直系同源基因。把它们的蛋白序列放在一起比对，可以把不同序列中来源于同一祖先位置的残基放在同一列，这种操作叫多序列比对（multiple sequence alignment，MSA）。

如果某一列在亲缘关系很远的物种中仍然相同，说明改变这个位置的代价较大，携带改变的个体在演化过程中被淘汰，这种现象叫纯化选择（purifying selection）。因此保守性可以作为“该位置具有功能重要性”的间接证据。

但是需要区分两个命题。第一，保守位置是否一定重要；第二，重要位置是否一定在癌症中高频突变。本文的分析实际上是在检验这两件事是否一致，结论是二者高度相关但并不完全重合。

### 1.5 使用的公共资源

- UniProt：蛋白序列与功能注释数据库，提供每条蛋白的唯一编号（accession），例如人的 p53 是 P04637。
- NCBI 与 Ensembl：基因、转录本与外显子信息。本次没有直接使用，但查找异构体（isoform）时会用到。
- Clustal Omega、MUSCLE、MAFFT：多序列比对工具。本次使用 Clustal Omega 的欧洲生物信息研究所（EMBL-EBI）在线服务。
- cBioPortal：肿瘤基因组数据门户，提供 REST 接口，可以按研究批量下载突变数据。
- COSMIC：体细胞突变数据库，需要注册后使用，本次未直接使用。
- IARC TP53 Database：专门收录 TP53 突变、胚系变异与功能实验结果的数据库。
- PDB（Protein Data Bank）：蛋白三维结构数据库，每个结构有四位编号，例如 1TUP。
- Crossref：DOI 注册机构提供的元数据接口，用于核对参考文献的标题、期刊、卷期页。

## 3. 步骤一：获取蛋白序列

### 3.1 检索策略

UniProt 提供 REST 接口。先用检索接口确认每个物种中 TP53 对应的条目：

    curl -G 'https://rest.uniprot.org/uniprotkb/search' \
      --data-urlencode 'query=gene:tp53 AND organism_id:9606 AND reviewed:true' \
      --data-urlencode 'fields=accession,id,protein_name,organism_name,length' \
      --data-urlencode 'format=tsv'

参数含义如下。gene:tp53 表示基因名为 tp53；organism_id 是 NCBI 分类编号，9606 是人，10090 是小鼠，9913 是牛，9031 是鸡，8355 是非洲爪蟾，7955 是斑马鱼；reviewed:true 表示只取人工审阅过的条目（Swiss-Prot），这类条目注释质量较高；fields 指定返回哪些列；format=tsv 表示制表符分隔的文本。

为什么加 reviewed:true：自动注释条目（TrEMBL）数量多，但可能存在错误剪接、错误起始位点等问题。作业只需要每条序列一个可靠代表，使用人工审阅条目更稳妥。

### 3.2 下载 FASTA

确认编号后直接按编号下载：

    curl 'https://rest.uniprot.org/uniprotkb/P04637.fasta' -o data/sequences/P04637.fasta

FASTA 格式由两部分组成：以大于号开头的描述行，以及其后的序列行。描述行包含数据库、编号、条目名、物种、基因名等信息。

### 3.3 为什么选这六个物种

人、牛、鼠是哺乳动物，鸡是鸟类，蛙是两栖类，斑马鱼是鱼类。它们覆盖了从硬骨鱼到哺乳动物约 4.5 亿年的演化距离。选择远缘物种的目的是让保守性具有区分度：如果只用人和鼠，二者分化时间短，绝大多数位置都相同，无法区分哪些位置受到更强的约束。

### 3.4 检查

下载后做了三项检查。第一，长度是否符合预期：人 393、牛 386、鼠 390、鸡 367、蛙 363、斑马鱼 373 个氨基酸。第二，序列是否以甲硫氨酸（M）开头，是否符合起始密码子的预期。第三，序列中是否出现 X，X 表示未知氨基酸，出现 X 会影响熵的计算。

这里有一个实际操作问题，值得单独记住。按物种逐个检索时，牛与斑马鱼的查询曾返回空结果。空结果并不代表数据库中不存在这两个条目。实际上 P67939 与 P79734 的 FASTA 描述行都以 sp 开头，表示它们都是人工审阅条目（Swiss-Prot）。空结果来自当时的网络中断，服务器没有返回数据。最终的处理方式是改为按编号直接下载 FASTA，再用长度与描述行核对。这件事说明：网络错误、请求超时与“数据库中确实没有”是三种不同的情况，脚本应当把 HTTP 错误与空结果分开处理，不能把两者都当作“没有数据”。

### 3.5 注意事项

- 同一基因可能有多个异构体（isoform）。例如 TP53 存在 Δ133p53、Δ160p53 等异构体，长度和结构域不同。UniProt 的主条目通常对应规范异构体（canonical isoform），本次全部使用主条目。
- 不同数据库的编号体系不同：UniProt 用 P04637 这样的 accession，NCBI 用 NP_000537 这样的 RefSeq 编号，Ensembl 用 ENST 开头的转录本编号。跨数据库合并数据时必须先统一编号。
- 数据库会更新。今天的序列与一年后的序列可能不同，因此要记录下载日期。

## 4. 步骤二：多序列比对

### 4.1 原理

多序列比对要解决的问题是：给定若干条长度不同、含有插入和缺失的序列，找出它们之间的同源位置，并把同源位置排在同一列。

常用方法是渐进式比对（progressive alignment）。先两两比较所有序列，计算相似度，构建一棵指导树（guide tree）；然后从最相近的一对开始比对，把结果作为一个整体，再与下一条序列比对，逐步加入直到全部序列。Clustal Omega 使用 mBed 方法快速聚类，并用隐马尔可夫模型（HMM）剖面进行后续比对。

比对过程中使用替换打分矩阵（例如 BLOSUM62）评价两个氨基酸相似的得分，使用空位罚分（gap penalty）控制插入空位的代价。罚分越高，比对越倾向于不引入空位。

### 4.2 提交任务

EBI 的 Clustal Omega 服务采用“提交—轮询—取结果”的流程：

    curl -X POST 'https://www.ebi.ac.uk/Tools/services/rest/clustalo/run' \
      --data-urlencode 'email=student@connect.hku.hk' \
      --data-urlencode 'stype=protein' \
      --data-urlencode 'sequence@results/alignment/all_tp53.fasta'

返回的内容是任务编号。之后每隔几秒查询状态：

    curl 'https://www.ebi.ac.uk/Tools/services/rest/clustalo/status/<job-id>'

状态变为 FINISHED 后取比对结果：

    curl 'https://www.ebi.ac.uk/Tools/services/rest/clustalo/result/<job-id>/aln-clustal_num'

结果格式并不都能取到。本次尝试 aln-clustalw 时返回错误 The requested model stream renderer 'aln-clustalw' is not available，说明该服务没有这一渲染器。改用 aln-clustal_num 后成功，得到带列号的 Clustal 格式文本。指导树用 phylotree 取回，为 Newick 格式。

### 4.3 结果解读

比对长度 409 列，人序列长 393 个氨基酸，多出的 16 列是其他物种插入而人序列为空位的位置。

Clustal 格式中，星号表示该列所有序列的氨基酸完全相同，冒号表示强相似替换，点表示弱相似替换，空格表示不相似。DBD 区域星号密集，N 端与 C 端稀疏，这一观察是后续定量分析的起点。

![比对结果](assets/r/fig1_alignment.png)

**图 1（正式报告图 1）| 六个物种的 p53 比对与逐列保守性。** 每个格子的颜色由该列保守性决定，颜色越深表示越保守，米色格子为比对空位；人序列行有边框；下方曲线为保守性得分。可以看出 DBD 区段的颜色明显深于两端。

### 4.4 注意事项

- 末端比对不可靠。N 端与 C 端长度差异大，比对算法在这些区域引入大量空位，得到的“低保守性”可能只是比对假象，不能直接解释为功能差异。
- 空位（gap）不是突变。它表示比对为了对齐而插入的位置，不代表某个物种真的缺失了这一段。
- 比对参数会影响结果。本次全部使用默认参数，并在报告中写明工具与版本。
- 序列数量少时比对稳定性下降。6 条序列足以看出大体格局，但不足以精确到单个残基。若要发表级别的结论，应使用 20 条以上的直系同源序列并检查比对的不确定性。

## 5. 步骤三：将保守性定量

### 5.1 为什么要定量

目视判断“这段比较保守”无法重复，也无法与突变频率做统计比较。定量后可以得到每个残基一个数值，用于排序、作图和检验。

### 5.2 Shannon 熵

对每一个比对列，统计 20 种氨基酸出现的频率 p，计算 Shannon 熵：

    H = - sum(p_i * log2(p_i))

单位是比特（bit）。如果该列在所有物种中都是同一种氨基酸，则只有一个 p 等于 1，其余为 0，H = 0。如果 20 种氨基酸等频率出现，H 达到最大值 log2(20) = 4.32。

### 5.3 保守性得分

为了让数值越大表示越保守，定义：

    conservation score = 1 - H / log2(20)

取值在 0 到 1 之间。1 表示完全不变，0 表示理论上最不保守。本次全体残基平均得分 0.795，DBD 平均 0.878，DBD 以外平均 0.714。

### 5.4 把比对列映射到人的残基编号

这一步容易出错，需要单独说明。比对结果有 409 列，而人的蛋白只有 393 个残基，因为其他物种有插入。如果直接把列号当作残基编号，后续与突变数据合并时就会错位。

正确做法是：从头遍历比对列，维护一个计数器；如果人序列在该列不是空位，则计数器加一，该列对应人的第计数器个残基；如果人序列在该列是空位，则该列是人序列的插入位置，不对应任何人的残基。

代码中这一逻辑写在 scripts/03_conservation.py 的循环里，输出的 conservation.csv 同时保留了 alignment_column 与 human_pos 两列，便于核对。

### 5.5 辅助指标

除了熵，本次还计算了两个指标。第一，一致率（identity to human）：在该列所有非空位的其他物种中，与人的氨基酸相同的比例。第二，Jensen–Shannon 散度（JSD）：该列的氨基酸组成与整个比对背景组成的差异，数值越大表示组成越特殊。

### 5.6 结果

137 个残基在六个物种中完全不变，占 34.9%。DBD 内 56.2% 的残基完全不变，DBD 以外只有 14.1%。这与“DBD 受更强功能约束”的预期一致。

### 5.7 注意事项

- 物种数少时，很多列的熵都是 0，得分同为 1.0。本次有 137 个残基并列最高，因此后续统计不能只用连续得分做比较，还要用“是否不变”这一二分变量。
- 空位比例高的列，得分不可靠。末端区域尤其明显。
- 保守性只是间接证据。真正判断一个残基是否重要，需要功能实验（转录激活活性、生长抑制实验等），保守性只能提供线索。

## 6. 步骤四：获取肿瘤突变数据

### 6.1 cBioPortal 的数据模型

cBioPortal 的数据按四层组织：研究（study）、分子谱（molecular profile）、样本列表（sample list）、突变记录（mutation）。一个研究可以包含多种分子谱（突变、拷贝数、表达等）；突变谱的编号通常以 _mutations 结尾；样本列表定义“哪些样本被检测过”；突变记录包含样本编号、基因、氨基酸改变、突变类型等字段。

### 6.2 研究筛选

本次的目标是 TCGA 泛癌数据集（Pan-Cancer Atlas）。先取全部研究列表，再筛选编号以 _tcga_pan_can_atlas_2018 结尾的研究，得到 32 个。

为什么是 32 而不是 33：TCGA 泛癌计划覆盖 33 种癌症类型，但 cBioPortal 把结肠腺癌（COAD）与直肠腺癌（READ）合并为一个研究 COADREAD，因此研究数为 32。

### 6.3 请求参数

每个研究发一个 GET 请求：

    https://www.cbioportal.org/api/molecular-profiles/<study>_mutations/mutations
      ?sampleListId=<study>_sequenced
      &entrezGeneId=7157
      &projection=SUMMARY

参数含义：sampleListId 指定该研究中经过测序的样本集合；entrezGeneId=7157 是 TP53 的 NCBI Gene 编号；projection=SUMMARY 表示只返回样本层面的记录，不按不同“层面”（如不同转录本）重复展开。

### 6.4 缓存与重试

cBioPortal 对请求频率有限制，并发较高时会返回 HTTP 429（请求过多）。网络偶发中断时会报 SSL EOF 错误。为此脚本做了三件事：每个研究的响应保存为 JSON 文件，若文件已存在则直接读取；失败时按递增间隔重试最多 8 次；把并发线程数降到 3。

这样做的结果是：第一次运行较慢（约 30 分钟），但中断后重新运行只补齐缺失的研究，不会重复下载。

### 6.5 数据清洗

合并 32 个文件后共 4,225 条记录。去重键为（样本编号、氨基酸改变、基因组起始位置、变异碱基）四项组合，用于去除同一突变在不同转录本下的重复记录。本次数据按该键去重后仍是 4,225 条，说明这批复用数据中没有重复记录。最终得到 4,225 条唯一突变，来自 3,839 个样本。31 个研究至少有一条 TP53 突变，葡萄膜黑色素瘤（UVM）为 0 条，这与该肿瘤 TP53 突变率极低的已知事实一致。

氨基酸改变字段的格式不统一，例如 R175H、R175Hfs*6、X125_splice、R213*。使用正则表达式 ^([A-Z])([0-9]+)([A-Z*])$ 提取野生型氨基酸、密码子编号与突变后氨基酸，只保留符合该格式的记录用于热点计数，共 3,295 条；不符合的记录（主要是剪接与部分移码）单独统计。

### 6.6 字段解释

- proteinChange：蛋白层面的改变，本文热点分析的主要依据。
- mutationType：突变类型，如 Missense_Mutation、Nonsense_Mutation、Frame_Shift_Del、Splice_Site。
- variantType：变异类型，如 SNP、DEL、INS。
- tumorAltCount 与 tumorRefCount：肿瘤样本中支持突变与支持参考的读段数，二者之比可估计突变等位基因频率（VAF）。

### 6.7 注意事项

- 必须用正则解析，不能直接按字符串比较。同一个 R175H 可能写作 R175H 或 p.R175H。
- 同一样本可能有多条记录，去重键要包含位置与变异碱基，否则会把不同突变误删。
- cBioPortal 的 TCGA 数据是体细胞突变。若要研究胚系变异，应查 IARC TP53 Database 或 ClinVar。
- 各研究样本量不同。跨癌种比较应使用突变比例，不能直接比较绝对条数。
## 7. 步骤五：识别突变热点

### 7.1 定义与计数方法

热点没有统一的数学定义。本次采用的操作定义是：在全部样本中，按密码子统计错义突变的条数，取条数最多的五个密码子。只统计错义突变，原因是无义与移码突变分布在基因全长，不形成单个密码子的聚集。

计数时使用 6.5 节解析出的密码子编号，按（密码子编号、野生型氨基酸）分组计数。结果保存在 results/tables/codon_mutation_counts.csv。

### 7.2 结果

五个热点及其错义突变条数为：R273 267 条、R248 224 条、R175 167 条、G245 91 条、R282 89 条。合计 838 条，占全部 4,225 条突变的 19.8%，占 2,731 条错义突变的 30.7%。

这五个密码子只占 393 个密码子的 1.3%，却承载了近五分之一的全部突变，这种集中程度是判断它们为驱动性热点的主要依据。

![热点](assets/r/fig3_hotspots.png)

**图 2（正式报告图 3）| 五个热点的替换谱。** 左图是矩阵：列为五个热点密码子，列标签附该密码子的错义突变总数与占全部 TP53 突变的百分比；行为突变残基，并按氨基酸类别分组（左侧类别标签）。格子中的数字与颜色深浅表示该替换的例数，空格表示没有观察到该替换。

### 7.3 替换谱

每个热点只涉及少数几种氨基酸替换，且分布高度偏斜：

- R175：H 占 89.8%，G 占 5.4%，C 占 4.2%。
- R248：Q 占 54.0%，W 占 39.7%，L 占 4.5%。
- R273：C 占 46.8%，H 占 37.8%，L 占 10.1%。
- G245：S 占 46.2%，D 占 20.9%，V 占 18.7%，C 占 11.0%。
- R282：W 占 95.5%，G 占 3.4%。

这种偏斜有生物学原因：R175、R248、R273、R282 都位于 CpG 位点，胞嘧啶甲基化后脱氨会形成 C 到 T 的转换，在密码子层面表现为精氨酸变为组氨酸（CGT 到 CAT）等特定替换。因此热点既反映功能选择，也反映突变产生的偏好。

### 7.4 与 IARC 数据库的差异

IARC TP53 Database 列出的经典热点是六个：R175、G245、R248、R249、R273、R282。本次数据中 R249 只有 47 条，排第六，未进入前五。原因是 R249S 与黄曲霉毒素暴露密切相关，在肝细胞癌中比例较高，而 TCGA 以欧美常见肿瘤为主，肝癌样本少，因此该位点的相对频率被压低。

这个差异说明：热点的排名依赖于队列构成，不能把某一次排序当作普遍规律。报告在讨论部分明确写出了这一点。

### 7.5 注意事项

- 队列构成会影响排名。肺癌、食管癌、高级别浆液性卵巢癌中 TP53 突变率很高，对总计数贡献大。
- CpG 位点的转换突变会放大某些密码子的频率。分析热点时应区分“突变产生偏好”与“功能选择”。
- 热点计数只说明复发，不直接证明驱动。严格的驱动判断需要功能实验或 dN/dS 类分析。
- 不同数据库的转录本编号可能不同，合并前必须统一到规范转录本。

## 8. 步骤六：统计检验

### 8.1 超几何检验

要回答的问题是：五个热点全部落在 137 个完全不变的残基中，这件事是否可能只是偶然。

把 393 个密码子看作总体，其中 137 个属于“不变”类别。随机抽取 5 个密码子，抽到的“不变”个数 X 服从超几何分布：

    P(X = k) = C(K, k) * C(N - K, n - k) / C(N, n)

其中 N = 393，K = 137，n = 5。五个全部不变对应 k = 5：

    P(X = 5) = C(137, 5) / C(393, 5) = 0.0049

也就是说，在随机情况下，五个密码子全部不变的概率约为 0.5%。这一结果支持“热点倾向于落在保守位置”的判断，但不证明因果关系。

### 8.2 Mann–Whitney U 检验

超几何检验把保守性简化为二分变量（不变或可变），损失了信息。Mann–Whitney U 检验直接比较两组连续得分：5 个热点的保守性得分与其余 388 个密码子的得分。

选择该检验的原因是它不要求数据服从正态分布，适合小样本与有界数据（得分在 0 到 1 之间）。本次单侧检验（备择假设：热点组更高）得到 P = 0.0048。

需要注意，热点组只有 5 个观测，检验效能很低。这个 P 值只能作为辅助证据，不能单独支撑结论。

### 8.3 Spearman 相关

要回答的问题是：把全部 393 个密码子放在一起，保守性越高的位置是否突变越多。

Spearman 相关系数基于秩（rank），不要求线性关系，对异常值不敏感。本次计算得到 ρ = 0.51，P = 3.3×10⁻²⁷。正相关说明保守位置确实更容易在肿瘤中发生错义突变。

相关不等于因果。合理的解释是：保守位置承担重要功能，这些位置一旦改变就会削弱 p53 功能，从而被肿瘤选择保留。但数据本身不能排除其他解释，例如某些保守位置同时处于突变热点序列上下文。

![保守性与突变](assets/r/fig5_conservation_vs_mutation.png)

**图 3（正式报告图 5）| 保守性与突变密度的关系。** 左图为保守性分布，完全不变的一类标红；中图为每个密码子的保守性与错义突变数；右图比较不同区域的每残基突变数。

### 8.4 效应量与多重比较

统计显著性之外，更值得关注的是效应量。DBD 内每个残基平均 13.6 条错义突变，DBD 以外只有 0.5 条，相差约 27 倍；保守半区 12.4 条，可变半区 0.6 条，相差约 20 倍。这些倍数比 P 值更能说明差异的实际大小。

本次只做了三个预设检验，没有进行多重比较校正。如果对很多分组反复检验，需要 Bonferroni 或 FDR 校正，否则假阳性率会升高。

### 8.5 注意事项

- 密码子之间不独立。相邻密码子共享突变上下文，样本也来自不同癌种，严格来说应使用混合效应模型，本次为简化未做。
- P 值受样本量影响。4,225 条突变使很小的差异也会显著，因此必须同时报告效应量。
- 5 个热点的统计检验只能作为描述，不能当作强推断。

## 9. 步骤七：结构分析

### 9.1 PDB 与 1TUP

PDB 文件是文本格式，每条原子记录占一行，包含原子序号、原子名、残基名、链编号、残基序号、坐标与温度因子。文件头部还有 HELIX 与 SHEET 记录，描述二级结构。

1TUP 是 p53 核心结构域与 DNA 的复合物结构，分辨率 2.2 埃（Å，1 Å = 0.1 纳米）。文件中包含三条 p53 链（A、B、C）、两条 DNA 链（E、F）和一个锌离子。p53 链的残基编号从 94 附近开始，与全长编号一致，但缺少 N 端与 C 端。

### 9.2 为什么需要选择链

三条 p53 链在晶体中的位置不同，只有部分链与 DNA 直接接触。如果随意选一条链计算距离，可能得到“R273 距离 DNA 11.9 Å”这样的结果，与已知的 DNA 接触结论矛盾。

本次的做法是：对每条蛋白链，统计与 DNA 重原子距离小于 4 Å 的残基数，选择接触数最多的链。计算结果选中链 B，在该链上 R248 与 DNA 的距离为 2.26 Å，R273 为 2.54 Å，与文献一致。

### 9.3 溶剂可及表面积

溶剂可及表面积（solvent accessible surface area，SASA）衡量一个残基有多少表面暴露在溶剂中。数值越小，说明残基越埋藏于蛋白内部。

本次使用 Shrake–Rupley 算法：在每个原子表面均匀取点，检查每个点是否被其他原子遮挡，未被遮挡的点数乘以每个点代表的面积，得到 SASA。取点越多结果越精确，本次使用 Biopython 的默认参数。

绝对 SASA 与残基大小有关，因此换算为相对值：相对 SASA = 绝对 SASA / 该残基类型的理论最大 SASA。理论最大值取自 Tien 等人 2013 年发表的标准表。一般把相对 SASA 小于 20% 视为埋藏。

### 9.4 距离计算

对每个残基，取全部重原子（非氢原子），与 DNA 或锌离子的全部重原子计算欧氏距离，取最小值。使用重原子而不是包含氢原子，是因为晶体结构中氢原子通常不可见。

### 9.5 结果

- R248：相对 SASA 57.8%，距 DNA 2.26 Å，位于 DNA 结合界面，侧链暴露。
- R273：相对 SASA 25.5%，距 DNA 2.54 Å，同样位于 DNA 界面。
- R175：相对 SASA 2.4%，距 DNA 11.0 Å，深埋于核心。
- G245：相对 SASA 0%，距 DNA 8.1 Å，完全埋藏。
- R282：相对 SASA 2.0%，距 DNA 9.6 Å，深埋。

结果把五个热点分成两类：R248 与 R273 直接接触 DNA，改变它们会破坏序列特异性结合；R175、G245、R282 埋藏在核心，改变它们会破坏局部折叠或锌结合位点的稳定性。两类机制最终都导致 p53 无法正常结合 DNA 并激活下游基因。

图 6 的两个结构视图没有用 matplotlib 的三维散点，而是用 PyMOL 渲染。原因是三维散点只能画出 Cα 轨迹和几个球，无法表现二级结构与侧链方向。PyMOL 脚本（scripts/07_render_fig6_pymol.py）使用开源版 PyMOL，在无显示器的服务器上通过 OSMesa 进行软件渲染：加载 1TUP，删除水分子与另外两条 p53 链，只保留与 DNA 接触的链 B 及 DNA 双链；蛋白用灰色飘带，DNA 用橙色飘带，锌离子用紫色球，五个热点侧链用红色或蓝色棍状模型；标签放在朝向相机的方向，避免被飘带和 DNA 遮挡，并用虚线连接标签与残基。渲染结果为 1500×1500 的 PNG，再由 R 的网格布局与右侧的溶剂可及性柱状图组合。使用 PyMOL 前应确认许可条款（https://www.pymol.org/），本次使用开源版本仅用于课程学习。

![结构](assets/r/fig6_structure.png)

**图 4（正式报告图 6）| 热点的结构位置。** 两个视图由 PyMOL 渲染：灰色飘带为 p53 核心结构域，橙色为 DNA，红色棍状为 DNA 接触热点（R248、R273），蓝色棍状为埋藏的结构性热点（R175、G245、R282），紫色球为 Zn²⁺；右侧柱状图为各热点的相对溶剂可及性。

### 9.6 注意事项

- 晶体结构是静态结构，溶液中的构象存在波动，距离数值应作为近似。
- 部分侧链在电子密度中不可见，文件中缺失原子，会使计算出的距离偏大。
- 1TUP 的残基编号与 UniProt 一致，但覆盖范围只有核心结构域，N 端与 C 端无法用该结构分析。
- 不同 PDB 条目（如 1TSR、2OCJ）的晶体堆积不同，距离数值会有差异，报告中必须写明使用的条目。

## 10. 步骤八：作图

### 10.1 基本原则

先得到可靠的表格，再作图。图只回答一个明确的问题。坐标轴必须有标签与单位。颜色数量控制在七种以内。避免使用双 y 轴，因为两条轴的相对位置可以人为调整，容易误导。

本次所有图使用同一套配色：结构域用固定颜色，热点统一用红色，其余用蓝灰色系。这样读者在不同图之间可以用颜色对应同一概念。

### 10.2 各图的制作要点

图 1（比对图）：把 409 列乘以 6 条序列画成矩阵，每个格子填一个字母，背景色由该列保守性得分决定。人序列行加边框突出。下方画保守性曲线与结构域条。热点位置用虚线标出。制作难点是字母密度高，字号必须小，同时保证导出分辨率足够。

图 2（跨物种比较）：左侧用 Biopython 读取 Newick 指导树，手动递归绘制矩形树；中间用条形图比较全长与 DBD 的一致率；右侧用箱线图加散点展示各结构域的保守性分布。

图 3（热点）：左侧用矩阵展示替换谱——列为热点密码子，行为突变残基并按类别分组，格内数字为例数；右侧用条形图展示全部突变的后果分类。

图 4（沿序列分布）：上下两轨共享 x 轴。上轨是保守性曲线，下轨是每个密码子的错义突变数，使用对数坐标，否则 R273 的 267 条会把其他位点压得看不见。最下方画结构域条。

图 5（统计关系）：左图是保守性直方图，把完全不变的一类标红；中图是保守性对突变数的散点图，使用对数纵轴；右图是比较不同区域突变密度的柱状图。

图 6（结构）：先用 PyMOL 渲染两个视图（a 为 DNA 界面，b 为隐藏 DNA 的旋转视图），保存为 1500×1500 的 PNG，再用 R 的网格布局与右侧柱状图组合。PyMOL 中把标签放在朝向相机的方向，避免被飘带和 DNA 遮挡，并用虚线连接标签与残基。

### 10.3 常见问题

- 标签重叠：热点之间只差几个残基时，标签会叠在一起。解决方法是交错高度或旋转文字。
- 坐标截断：文字超出坐标范围会被裁掉，需要设置 clip_on=False 或调整边距。
- 图例遮挡数据：把图例移到空白区域，或直接在数据旁标注。
- 分辨率不足：报告用图至少 300 dpi，本次全部按 300 dpi 导出 PNG。
- 字体缺失：中文标签需要系统中存在中文字体，matplotlib 默认字体不含中文。

### 10.4 输出管理

图片统一放在 assets 目录，文件名与图号一致（fig1_alignment.png 等）。报告中使用相对路径引用。图号调整时（本次曾把热点图与分布图互换编号），必须同步修改文件名、图内标题与正文引用，否则会出现图 3 指向图 4 的错误。

## 11. 步骤九：写作与文献

### 11.1 报告结构

正式报告分为六节：跨物种保守性、五个热点、热点与保守性的关系、讨论、要点、数据库的作用。前面加一句字数说明，后面附方法附录与参考文献。

方法附录写清数据来源、工具版本、统计方法与结构选择，目的是让别人能够重复。正文只保留结论与关键数字，详细内容放在图、表与方法中。

### 11.2 字数控制

作业要求正文 300 至 400 词，不含图与参考文献。为了避免凭感觉估计，写作阶段用了一个统计脚本（该脚本未纳入最终仓库）。统计口径是：只统计 Results 与 Discussion 的普通段落，跳过标题行、表格行、图片行、图注行与参考文献。

最终统计结果为 396 词（Results 与 Discussion 合计），符合 300 至 400 词的要求。中文版按同样内容翻译，按汉字计约 520 字。

需要注意，不同软件的字数统计口径不同。Word 会把连字符连接的词算作一个词，也会把括号内的编号算作词。脚本采用按空白切分的方式，与 Word 接近但不完全一致，因此留出了约 8 词的余量。

### 11.3 参考文献核验

初稿的参考文献是凭记忆写出的，存在错误风险。核验方法是使用 Crossref 的 DOI 接口逐条查询：

    curl 'https://api.crossref.org/works/10.1038/msb.2011.75'

返回的 JSON 包含标题、期刊、年、卷、期、页与作者列表。把返回字段与稿件逐项比对。

本次核验发现两处错误：

第一处，Hoadley 等人 2018 年 Cell 论文的 DOI 写成了 10.1016/j.cell.2018.03.046。查询该 DOI 返回的是另一篇题为 Coupling Neurogenesis to Circuit Formation 的文章，页码 288 至 290，与 TP53 无关。正确 DOI 是 10.1016/j.cell.2018.03.022。

第二处，Joerger 与 Fersht 2008 年的综述标题写成了 Structure–function–residue relationships in the p53 DNA-binding domain，这个标题并不存在。正确标题是 Structural biology of the tumor suppressor p53。

此外，UniProt 2025 年那篇文献的标题补全为 UniProt: the Universal Protein Knowledgebase in 2025，卷期页补为 53(D1):D609–D617。

核验完成后，把 DOI 写进参考文献列表，读者可以直接点击验证。

### 11.4 EndNote 文件

为了让文献可以直接导入文献管理软件，生成了两个文件：

- references/references.ris：RIS 格式，EndNote、Zotero、Mendeley 都可以导入。
- references/references_endnote.xml：EndNote 自带的 XML 格式。

EndNote 的导入步骤是：File 菜单，选择 Import，选择 File，选中 references.ris，Import Option 选择 Reference Manager (RIS)，Duplicates 选择 Import All，点击 Import。XML 文件的 Import Option 选择 EndNote generated XML。

RIS 是纯文本格式，每条记录以 TY 开头、以 ER 结尾，字段用两个字母加连字符表示，例如 AU 表示作者、TI 表示标题、JO 表示期刊。可以用文本编辑器直接查看与修改。

需要说明一点：Hoadley 与 de Bruijn 两篇论文的作者有数百人，文献文件中只保留前 10 位作者，这是引用列表的常见做法，EndNote 的期刊样式会自动补上 et al.。

## 12. 排错记录

| 现象 | 原因 | 解决方法 |
|---|---|---|
| ModuleNotFoundError: matplotlib | 系统 Python 未安装该库 | 建立虚拟环境并安装依赖 |
| numpy 导入报 code signature 错误 | 解释器启用库验证，pip 安装的二进制签名不一致 | 改用 /usr/bin/python3 建立虚拟环境 |
| Clustal Omega 返回 renderer not available | 该服务不提供 aln-clustalw 格式 | 改用 aln-clustal_num |
| cBioPortal 返回 HTTP 429 | 请求频率超过限制 | 降低并发到 3，增加重试间隔 |
| cBioPortal 连接报 SSL EOF | 网络中断 | 重试并缓存已完成的研究 |
| pandas 报 KeyError: n_missense | 分组后的子表没有该列 | 改为从当前行取值 |
| 图中热点位置为空 | 用了占位热点表测试流程 | 用真实结果重新生成全部中间文件 |
| 图号与正文顺序不一致 | 先画分布图后画热点图 | 交换编号并重命名文件，同步修改标题与引用 |
| 中文图注与图内英文不一致 | 图由英文脚本生成 | 在报告开头说明图内标注为英文 |

这些问题的共同点是：错误信息通常直接指出原因，但需要理解工具的工作方式才能判断。例如 429 是服务器主动限流，不是网络故障；code signature 错误与代码无关，是运行环境的安全机制。

## 16. 结语

本次分析的核心结论是：TP53 的五个高频突变位点全部位于 DNA 结合结构域，并且在六个脊椎动物中完全不变；结构上它们分为直接接触 DNA 与维持核心折叠两类。保守性与肿瘤突变频率之间存在明显正相关，但保守位置远多于热点位置，说明保守性只能预测功能重要性，不能单独预测突变频率。

方法上最值得记住的三点是：第一，任何序列编号的映射都要单独验证，比对列号与残基编号不是一回事；第二，公开数据库的接口需要缓存与重试，否则网络问题会中断整个流程；第三，参考文献必须逐条核对 DOI，凭记忆写出的条目可能出现 DOI 与标题错误。
